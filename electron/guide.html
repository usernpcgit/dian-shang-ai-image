🚀 欢迎使用 电商AI生图（桌面版）

免费侧载版本 · 首次使用需手动放行一次

⚠️ 未签名应用从网上下载后会被 macOS 打上「隔离标记」，首次打开会被拦截（提示"无法验证开发者"或"已损坏"）。
只需右键 App →「打开」放行一次（或用下方终端命令清标记），之后就能正常双击启动。

📦 方法 A：下载 ZIP 版本（推荐）

ZIP 和 DMG 都会被浏览器打上隔离标记，所以解压/拖出后首次打开都要放行一次（不是"双击就能用"）。步骤如下：

  1. 去 GitHub Releases 页下载 xxx-mac.zip（不是 .dmg）
  2. 解压得到「电商AI生图.app」
  3. 不要直接双击——请右键 App →「打开」 → 弹窗里再点「打开」
  4. 此后就会加入系统白名单，以后双击即可正常启动 ✅

💡 进阶：用终端下载可彻底不带隔离标记（双击即开）：
curl -L -o 电商AI生图.zip <发布页里的 zip 链接> && unzip 电商AI生图.zip

💻 方法 B：DMG 版本 + 终端命令

如果你用的是 DMG 安装包，在终端（Terminal）中依次执行以下两条命令：

终端 / Terminal
xattr -cr ~/Applications/电商AI生图.app && echo ✅ 已清除隔离标记

这条命令会递归清除 App 及其内部所有文件的 macOS 隔离属性（quarantine / macl 等）。
如果你把 App 放在了桌面，把路径中的 ~/Applications/ 改成 ~/Desktop/

终端 / Terminal
open ~/Applications/电商AI生图.app

用 open 命令启动可以绕过某些 GUI 层面的二次检查。

⚙️ 方法 C：临时关闭 Gatekeeper（最暴力但 100% 有效）

终端 / Terminal（需要输入密码）
sudo spctl --master-disable && xattr -cr ~/Applications/电商AI生图.app && open ~/Applications/电商AI生图.app

打开成功后建议恢复：sudo spctl --master-enable

🪟 Windows SmartScreen 提示处理

  1. 安装或运行时若弹出 "Windows 保护了你的电脑"（SmartScreen）
  2. 点击 「更多信息」
  3. 点击 「仍要运行」
  4. 应用正常启动 ✅

这是 Windows 对未签名应用的标准安全提示，不是病毒。本应用不含任何恶意行为。

💡 如果提示"代理启动失败"或找不到 proxy-bin.exe：
这是正常的回退机制——应用会自动尝试用系统 Python 启动后端服务。
请确保电脑已安装 Python 3.8+（从 python.org 下载）。
