一、这是什么

一个双击就能打开的电商内容小工具，专门给做电商详情页、海报的运营小伙伴用。不用装软件、不用注册、不用联网（除非你要接生图 API）。所有数据都存在你自己的电脑浏览器里。

二、第一次怎么用（做一张详情页）

  1. 打开「做详情页」页（默认就在这）。
  2. 最上方「第 0 步」上传一张产品白底图（图上只有产品、背景纯白/透明最好）。它是 AI 生图的底图，10 屏共用，只需传一次。
  3. 点「先挑一个风格」选一套配色（默认是天空蓝，还有甜粉梦幻 / 高级黑金 / 清新森系 / 国潮 / 简约白）。
  4. 上方点 第几屏，填标题/文案，右边实时预览效果。
  5. 点内容面板的「🤖 AI 生成这张屏」（或去「API」面板填好 redfox Key 后点生成）：工具把白底图 + 这屏提示词发给 gpt-image-2，生成场景图并自动叠字。
  6. 满意了点「导出这张 PNG」，或「导出全部 10 张」一次性出片。

三、怎么更换生图风格

在「做详情页」页最上方有一个 风格选择条（默认是天空蓝，还有甜粉梦幻 / 高级黑金 / 清新森系 / 国潮 / 简约白）。点一下就切换，所有屏的配色立刻跟着变。

下面还有一行「当前风格的生图提示词前缀」——这是给 AI 生图用的"画面调性词"（比如"清新梦幻、浅粉浅蓝"）。你换风格时它会自动跟着改，也能自己手动改，让生出来的图更贴你的品类。

四、提示词怎么用

  1. 切到「提示词库」页，写一条：填标题、分类（如"详情页/海报"）、标签、正文（就是提示词内容），点保存。
  2. 以后在上方搜索框搜关键词就能找到，点「编辑」可改、点「删除」可删。
  3. 用法：把这库的提示词复制到任意 AI 生图工具（比如对话里让我生图、或你自己的生图平台）去生成图片，再把图回到「做详情页」上传叠字。

五、怎么让工具自己调图生图（图生图）

本工具用 图生图：把你上传的白底产品图当作底图，加上每屏的提示词，调用生图接口生成电商场景图，再自动叠字。在「做详情页」的「API」面板里：

  1. 先选生图服务商下拉框：
    • Pollinations（免 Key）：完全免费、不用注册，直接试文生图（图生图能力弱）。
    • Gemini（Google 免费层）：去 aistudio.google.com 拿 Key，每日约 500 张，支持图生图。
    • OpenAI（gpt-image-2）：去 platform.openai.com 拿 Key，新号有试用金，支持图生图。
    • redfox.hk：去 redfox.hk 拿 Key（现多为付费）。
    • 自部署 / 自定义端点：对接你自己的模型（本地 ComfyUI、自建 OpenAI 兼容服务，或任意充值付费的兼容端点），填 Base URL 即可。
  2. 按所选服务商填 Key（Pollinations 不用填；自定义端点填 Base URL）。Key 会自动记住。
  3. 第一次用本地版，双击本目录里的「启动.command」 —— 它会开一个本地小代理并自动打开工具（纯前端直连各家接口会被跨域拦截，必须经过这个代理；代理只转发请求，不存你的图）。公网版已经自带代理，不用这一步。
  4. 回到内容面板点「🤖 AI 生成这张屏」，工具自动完成：上传白底图 → 调所选接口 → 生成场景图 → 叠字预览。
⚠️ 说明：白底产品图是必填的（图生图必须有底图；Pollinations 仅文生图可免图）。如果暂时不想接 API，也可以手动在每屏「上传这张屏的底图」放一张现成图，照样能叠字导出。代理关掉后，纯前端模式只能做"手动传图 + 叠字"，不能联网生图。

六、常见问题

  • 数据会不会丢？ 提示词和素材存在你这台电脑的浏览器里，关掉再开还在；但清浏览器缓存/换浏览器会没，重要内容记得导出备份。
  • 换电脑还能用吗？ 把这个 HTML 文件拷贝过去双击就行，但里面的数据不跟着文件走（存在原电脑浏览器）。
  • 能批量导出 zip 吗？ 当前是逐张下载，已满足绝大多数场景；需要打包可后续加。
