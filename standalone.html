一、这是什么

一个双击就能打开的电商内容小工具，专门给做电商详情页、海报的运营小伙伴用。不用装软件、不用注册、不用联网（除非你要接生图 API）。所有数据都存在你自己的电脑浏览器里。

二、第一次怎么用（做一张详情页）

  1. 打开「做详情页」页（默认就在这）。
  2. 最上方「第 0 步」上传一张产品白底图（图上只有产品、背景纯白/透明最好）。它是 AI 生图的底图，10 屏共用，只需传一次。
  3. 上方点 第几屏，填标题/文案，右边实时预览效果。
  4. 切到「内容」面板，写一句提示词（想让 AI 生成什么样的电商图，越具体越好），可选上传底图 / 参考图，点「🤖 生成电商图」，AI 直接出图放入本屏。也可在下方「叠字内容」填标题文案叠加导出。
  5. 满意了点「导出这张 PNG」，或「导出全部 10 张」一次性出片。

三、素材库（竞品情报）怎么用 🔍

切到「🖼 素材库」页，这里是你的竞品情报中心——把各平台高销量商品链接粘贴进来，AI 自动抓取并分析它的主图套路、标题策略、SKU 设计、详情页逻辑。标记为「生图参考」后，生成电商图时 AI 会自动偷师这些套路，出品更聪明高效。

  1. 在「添加竞品」卡片粘贴商品链接（淘宝 / 京东 / 拼多多 / 抖音 / 1688 / Amazon 均可），点「↓ 抓取」按钮——工具自动抓标题 / 平台 / 价格 / 主图，一步到位填入下方字段。
  2. 如果抓不到主图，可以手动上传图片、粘贴图片 URL 或直接 Ctrl+V 粘贴截图。
  3. 确认信息无误后点「🤖 上传并让 AI 学习」，AI（智谱 GLM）会真实分析该竞品的视觉策略（有主图时会真「看」图），分析约 20–60 秒。
  4. 分析完成后，竞品卡片上会出现「✅ 已分析」标记和「🎯 标记为生图参考」开关——打开它，后续生成电商图时 AI 会自动注入这个竞品的分析结论作为参考。
  5. 页面顶部有状态栏显示当前有多少个竞品被标记为「生图参考」，可一键清空。
  6. 已添加的竞品支持：查看详情（展开看 AI 分析结论）、编辑、删除；也可用搜索框按标题/平台/标签筛选。
⚠️ 说明：竞品分析走智谱 GLM 接口，需要联网；纯本地无网时抓取功能仍可用（仅抓取基础字段），但 AI 分析部分会报错。已分析的结论存在浏览器本地存储中，下次打开还在。

四、提示词怎么用（AI 反推 🤖）

「📝 提示词库」页已升级成 AI 反推生图提示词：上传一张产品白底图、告诉 AI 你的卖点，它自动分析产品特征并写出多条专业生图提示词，不用自己憋词。

  1. 切到「📝 提示词库」页，在「📦 产品信息」卡片点击或拖拽上传一张产品白底图（图上只有产品、背景纯白 / 透明最好，建议 800px 以上）。
  2. 在「产品卖点 / 特点」里写清楚：材质工艺、颜色 / 色系、目标人群、使用场景等——越具体，AI 反推越准。
  3. 选「生成风格」芯片：详情页主图 / 海报 / 种草文默认勾选，还可勾场景图 / 短视频封面 / 小红书风，可多选。
  4. 点「🤖 AI 反推提示词」，等约 10–20 秒。
  5. 结果区先给出「🔍 产品分析」（AI 对产品类型 / 颜色材质 / 构图的识别结论）；下方每条提示词卡片可：📋 复制（粘到任意生图工具）、💾 存入库（存进下方本地库）、🎨 拿去生图（直接调用本工具的 AI 生图出图）。
  6. 存入库后，在下方「💾 已保存的提示词」搜索框搜关键词就能找到，点「编辑」可改、点「删除」可删。
⚠️ 说明：AI 反推用的是智谱 GLM（看图 glm-4v-flash + 生文 glm-4-flash，免费接口），需要联网；纯本地打开没网时这部分会报错，但工具其它功能照常。

五、怎么用 AI 生图（文生图 / 图生图）

在「做详情页」→「内容」面板就能直接生图，支持两种模式：

  • 文生图：只写提示词，AI 直接生成电商图（Pollinations 免 Key 可立刻试；Seedream / Gemini / OpenAI 需填对应 Key）。
  • 图生图：上传底图（顶部「底图」，白底产品图最佳）+ 提示词，让 AI 把产品放进你写的场景里。redfox 只支持图生图，必须此模式。

还能在「内容」面板的参考图库上传若干参考图（风格 / 版式），生成时多选几张，AI 会参考它们，让出品更统一。

先选生图服务商（在「API」面板）：

  • Pollinations（免 Key）：完全免费、不用注册，直接试文生图（仅文生图）。
  • Gemini（Google 免费层）：去 aistudio.google.com 拿 Key，每日约 500 张，支持图生图。
  • OpenAI（gpt-image-2）：去 platform.openai.com 拿 Key，新号试用金，支持文 / 图生图。
  • Seedream 5.0（字节火山）：去 火山方舟 开通并拿 ARK API Key，国内直连、图生图保真好。
  • redfox.hk：去 redfox.hk 拿 Key（现多为付费）。
  • 自部署 / 自定义端点：对接你自己的模型（本地 ComfyUI、自建 OpenAI 兼容服务，或任意充值付费的兼容端点），填 Base URL。
⚠️ 说明：底图不是必填——做文生图只写提示词即可；做图生图才需要底图。公网版已自带代理，不用双击「启动.command」；若公网生图频繁超时，可在电脑双击「启动.command」走本地代理（国内网络更稳）。代理只转发请求，不存你的图。

六、常见问题

  • 数据会不会丢？ 提示词和素材存在你这台电脑的浏览器里，关掉再开还在；但清浏览器缓存/换浏览器会没，重要内容记得导出备份。
  • 换电脑还能用吗？ 把这个 HTML 文件拷贝过去双击就行，但里面的数据不跟着文件走（存在原电脑浏览器）。
  • 能批量导出 zip 吗？ 当前是逐张下载，已满足绝大多数场景；需要打包可后续加。
