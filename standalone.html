一、这是什么

一个双击就能打开的电商内容小工具，专门给做电商详情页、海报的运营小伙伴用。不用装软件、不用注册、不用联网（除非你要接生图 API）。所有数据都存在你自己的电脑浏览器里。

二、第一次怎么用（做一张详情页）

  1. 打开「做详情页」页（默认就在这）。
  2. 最上方「第 0 步」上传一张产品白底图（图上只有产品、背景纯白/透明最好）。它是 AI 生图的底图，10 屏共用，只需传一次。
  3. 上方点 第几屏，填标题/文案，右边实时预览效果。
  4. 切到「内容」面板，写一句提示词（想让 AI 生成什么样的电商图，越具体越好），可选上传底图 / 参考图，点「🤖 生成电商图」，AI 直接出图放入本屏。也可在下方「叠字内容」填标题文案叠加导出。
  5. 满意了点「导出这张 PNG」，或「导出全部 10 张」一次性出片。

三、怎么更换生图风格

在「做详情页」页最上方有一个 风格选择条（默认是天空蓝，还有甜粉梦幻 / 高级黑金 / 清新森系 / 国潮 / 简约白）。点一下就切换，所有屏的配色立刻跟着变。

下面还有一行「当前风格的生图提示词前缀」——这是给 AI 生图用的"画面调性词"（比如"清新梦幻、浅粉浅蓝"）。你换风格时它会自动跟着改，也能自己手动改，让生出来的图更贴你的品类。

四、提示词怎么用

  1. 切到「提示词库」页，写一条：填标题、分类（如"详情页/海报"）、标签、正文（就是提示词内容），点保存。
  2. 以后在上方搜索框搜关键词就能找到，点「编辑」可改、点「删除」可删。
  3. 用法：把这库的提示词复制到任意 AI 生图工具（比如对话里让我生图、或你自己的生图平台）去生成图片，再把图回到「做详情页」上传叠字。

五、怎么用 AI 生图（文生图 / 图生图）

在「做详情页」→「内容」面板就能直接生图，支持两种模式：

  • 文生图：只写提示词，AI 直接生成电商图（Pollinations 免 Key 可立刻试；Seedream / Gemini / OpenAI 需填对应 Key）。
  • 图生图：上传底图（顶部「底图」，白底产品图最佳）+ 提示词，让 AI 把产品放进你写的场景里。redfox 只支持图生图，必须此模式。

还能在「内容」面板的参考图库上传若干参考图（风格 / 版式），生成时多选几张，AI 会参考它们，让出品更统一。

先选生图服务商（在「API」面板）：

  • Pollinations（免 Key）：完全免费、不用注册，直接试文生图（仅文生图）。
  • Gemini（Google 免费层）：去 aistudio.google.com 拿 Key，每日约 500 张，支持图生图。
  • OpenAI（gpt-image-2）：去 platform.openai.com 拿 Key，新号试用金，支持文 / 图生图。
  • Seedream 5.0（字节火山）：去 火山方舟 开通并拿 ARK API Key，国内直连、图生图保真好。
  • redfox.hk：去 redfox.hk 拿 Key（现多为付费）。
  • 自部署 / 自定义端点：对接你自己的模型（本地 ComfyUI、自建 OpenAI 兼容服务，或任意充值付费的兼容端点），填 Base URL。
⚠️ 说明：底图不是必填——做文生图只写提示词即可；做图生图才需要底图。公网版已自带代理，不用双击「启动.command」；若公网生图频繁超时，可在电脑双击「启动.command」走本地代理（国内网络更稳）。代理只转发请求，不存你的图。

六、常见问题

  • 数据会不会丢？ 提示词和素材存在你这台电脑的浏览器里，关掉再开还在；但清浏览器缓存/换浏览器会没，重要内容记得导出备份。
  • 换电脑还能用吗？ 把这个 HTML 文件拷贝过去双击就行，但里面的数据不跟着文件走（存在原电脑浏览器）。
  • 能批量导出 zip 吗？ 当前是逐张下载，已满足绝大多数场景；需要打包可后续加。
